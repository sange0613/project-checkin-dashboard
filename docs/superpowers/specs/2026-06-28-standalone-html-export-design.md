# 独立 HTML 导出设计

## 目标

生成一个可单独复制或导入的 `.html` 文件，完整保留当前项目进度页面的界面和交互，无需携带 `assets` 文件夹。

## 方案选择

可选方案包括：

1. 单文件应用：把生产构建后的 CSS 和 JavaScript 内嵌到 HTML 中。文件稍大，但功能完整，最方便导入。
2. 静态快照：只保留当前画面。文件更简单，但无法打卡、编辑或保存。
3. HTML 加资源文件夹：沿用标准 Vite 构建。便于网站部署，但复制和导入时容易漏文件。

采用方案 1。

## 生成方式

- 先运行现有 Vite 生产构建。
- 读取构建后的 `dist/index.html`、CSS 和 JavaScript。
- 将样式写入 HTML 的 `<style>`，将程序写入 `<script type="module">`。
- 输出为项目根目录下的 `项目进度一览表.html`，便于直接交付。
- 提供可重复运行的构建脚本，后续页面更新后可以重新生成。

## 功能与数据

- 保留项目编辑、每日打卡、随机内容、阶段进度、日夜模式及全部快捷入口。
- 继续使用浏览器 `localStorage` 保存数据。
- 数据归属于打开或托管该 HTML 的浏览器来源；换设备、换浏览器或导入到不同网站时，不会自动带入旧数据，可继续使用页面已有的导入和导出功能迁移。

## 兼容性

- 文件可直接在现代浏览器中打开，也可导入允许执行 HTML、CSS 和 JavaScript 的平台。
- 如果目标平台会过滤 `<script>`，交互功能无法运行；这种限制不能由单文件本身绕过。
- 页面不依赖本地图片、字体或其他资源文件；右上角外部快捷入口仍需联网访问。

## 验证

- 自动检查输出文件只包含内联样式和脚本，不引用 `dist/assets`。
- 运行现有完整测试和生产构建。
- 在浏览器中通过本地文件地址打开，确认页面不是空白、控制台无应用错误、关键控件可见，并验证一次可保存的交互。
