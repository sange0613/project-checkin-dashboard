# 待办看板同步

右上角「待」在综合工具区打开 `https://sange0613.github.io/todolist/?suite=1`。使用项目页面的同一同步码，待办数据放在原同步文档的 `suite.apps.todo` 中，其他应用数据保持独立。

待办原网页的 `suite-loader.js` 加载本项目构建出的 `todo-sync/entry.js`。嵌入模式通过限定来源与 iframe 窗口的消息通道交换待办数据，不发送同步码。单独打开时使用相同域名下保存的同步码，也可在页面底部输入同步码。

`liubai-suite-sync-v1` 保存逐字段版本，`liubai-workspace-v2` 保持原待办格式。看板、分组、事项使用原始 ID，删除通过存在标记同步。正在编辑或拖动时延后显示远端变化，保存时只记录本机相对于编辑前内容的变化，再合并远端内容。初始示例不会自动上传。

个人 JSON 备份只在本机读取和导入 Firebase，不得作为源码、公开静态资源或测试夹具提交。首次导入后应核对看板、分组、事项数量，并检查数据回读。

发布顺序：先发布项目页面的同步模块，再发布待办原网页的适配器。两处都更新后，可在原网页和综合工具内使用同一码。
